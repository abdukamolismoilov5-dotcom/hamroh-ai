# Maxfiylik siyosati (qisqa)

- **Video va rasm** (videoregistrator, yo'l kamerasi) faqat telefonda saqlanadi. Ilova ularni o'zi yubormaydi; foydalanuvchi o'zi ulashishi mumkin.
- **Old kamera** (charchoq rejimi) hech narsa yozmaydi: faqat ko'z ochiqlik ko'rsatkichi (EAR) hisoblanadi.
- **Serverga yuboriladi:** chuqur, qattiq tormoz va foydalanuvchi xabarlari (tur, koordinata, vaqt) — anonim identifikator bilan; metan shoxobchasi holati; jonli safar (faqat foydalanuvchi yoqsa, tugagach 1 soatda yopiladi); SOS xabari (faqat avariyada).
- **Telefon raqami** (ixtiyoriy kirish) serverda faqat HMAC xesh ko'rinishida saqlanadi.
- **Oila kontaktlari** — Telegram chat identifikatori; foydalanuvchi yoki kontakt (/stop) istalgan vaqtda o'chiradi.
- **O'chirish:** Yana → Sozlamalar → "Barcha ma'lumotlarimni o'chirish" — telefondagi va serverdagi ma'lumotlar o'chadi.
- Server O'zbekiston hududida joylashtirilishi kerak (shaxsiy ma'lumotlarni mahalliylashtirish talabi).
- Ma'lumotlar bazasini "Shaxsga doir ma'lumotlar to'g'risida"gi qonun bo'yicha ro'yxatdan o'tkazish egasining vazifasi.
